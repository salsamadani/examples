---
description: Scaffold a new example project
---

Create a new example in this repository. Ask the user for:

1. **Language**: Go or TypeScript (or other)
2. **Name**: The example name (lowercase with hyphens, e.g., `my-example`)
3. **Description**: A brief description of what the example demonstrates

Then scaffold the example:

- Create the directory at the repo root (or under `ts/` for TypeScript)
- Add the appropriate project config (`go.mod`, `package.json`, etc.)
- Create a basic entry point with a hello-world style implementation
- Add a `README.md` explaining the example, prerequisites, how to run, and how to test

Follow existing examples in this repo as reference for structure and conventions.
